## Keep
- 기본적인 Git 협업 명령어 숙지 완료
- Docker: 이미지 → 컨테이너 실행 구조 이해
- Jenkins: GitHub webhook을 활용한 자동화 파이프라인 개념 정리



## Try
- Dockerfile을 직접 작성해서 이미지 빌드 → 컨테이너 실행
- Jenkins로 간단한 CI 파이프라인 구축

# 2025-07-22
## Review
- 자율주행 로봇 프로젝트에서 SLAM 기반 경로 탐색과 스팟 인식 전략에 대해 고민  
- 물류창고나 스마트팜과 같은 실제 환경에서 로봇이 정해진 위치(스팟)로 이동하고, 해당 위치에서 작업을 수행하는 구조를 어떻게 설계할 수 있을지 탐색  
- 기능이 사용자 중심으로 어떻게 제공될 수 있을지, 그리고 이를 웹과 연동하거나 WMS와 통합할 수 있는 가능성에 대해서도 고민




## Problem
- 로봇에게 "어디로 가야 하는가"라는 정보를 어떤 방식으로 전달할 수 있을지, 스팟의 정의 방식이 아직 추상적
- 스팟의 좌표를 직접 지정하는 것과 QR/마커 등으로 시각적으로 인식시키는 방식 중 어떤 접근이 더 현실적인지 판단이 필요




## Keep
- 자율주행 로봇은 SLAM 기반으로 맵을 구성하며, 특정 위치(스팟)에 대한 정의만 있으면 해당 지점으로 이동 가능하다는 원리
- "스팟"은 GPS 좌표, 좌표계 기반 픽셀 위치, 또는 QR/마커 기반 시각적 인식 등 다양한 방식으로 정의할 수 있음




## Try
- 사용자 관점에서 웹에서 설정할 수 있는 기능(예: 스팟 지정, 이동 명령, 상태 모니터링) 리스트업 및 UI 구상

## Review
와이어프레임을 제작
Figma를 활용해 전체 구조와 흐름을 시각화했으며, 실제 운영자가 사용할 웹 인터페이스를 염두에 두고 기획

- 메인1 페이지: 실시간 센서 정보 및 맵 뷰  
- 메인2 페이지: 로봇 상태 및 경로 제어 기능  
- 이슈 목록 페이지: 감지된 위험 알림 리스트  
- 이슈 상세 페이지: 개별 이슈 상세 정보 및 로그 확인

디자인 레퍼런스를 확보하기 위해 UI/UX 관련 사이트 및 대시보드 레이아웃 사례들을 조사하며, 참고 디자인을 수집했다.




## Problem
- 페이지 간 기능 흐름을 정리하면서 정보 배치 우선순위가 명확하지 않은 부분이 있어 반복적으로 구조를 조정하게 됨.




## Keep
- Figma를 활용한 다섯 개 페이지의 기본 와이어프레임 완성

# 2025-07-30
## Review
- 메인 페이지에서 SidebarItem을 클릭했을 때 해당 아이템의 상세 정보를 보여주는 사이드바 상세 창(SidebarDetail)을 구현
상세 창에는 선택된 아이템의 날짜, 사진, 리포트 내용 등이 포함되어 있으며, 클릭한 항목에 따라 동적으로 렌더링되도록 구성




## Problem
- context를 통해 리스트 전체 데이터에서 클릭한 항목의 정보를 정확히 가져와야 해서, 데이터 흐름과 state 관리가 중요
- 이미지, 날짜, 리포트 내용 등 다양한 형태의 데이터를 조건 없이 예외 없이 보여주도록 로직 정리
- 사이드바 형태로 띄우는 UI의 경우, 자연스럽게 열리고 닫히는 애니메이션이나 UX가 추가로 고려 됨



## Keep
- onClick 이벤트를 통해 SidebarItem을 누를 때 해당 데이터를 context 또는 props로 상세창에 전달하는 방식이 잘 동작함
- 리포트 내용은 별도 컴포넌트로 분리하여 유지보수성과 재사용성을 높였다
- 날짜와 이미지 등은 조건부 렌더링을 사용하여 유연하게 처리



## Try
- 사이드바 닫기 기능 및 외부 클릭 시 닫히는 로직 추가 고려
