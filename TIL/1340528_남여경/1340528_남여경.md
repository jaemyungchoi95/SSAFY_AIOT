# 2025-07-18
## Review
- 감정 다이어리 프로젝트에서 Editor 컴포넌트의 감정 선택 리스트, 작성 완료 버튼 클릭 후 이동 로직 등을 점검하고 수정했다.
- New.jsx에서 작성된 일기를 onSubmit을 통해 처리한 후 useNavigate로 홈으로 이동하도록 구성되어 있었음.
- 전반적으로 React의 props, context, event, routing 흐름을 실전 디버깅을 통해 복습할 수 있었다.


## Problem
- 날짜 입력 필드에서 name="createDate"로 오타 → 상태 업데이트 안 됨 → 이후 getTime() 호출 시 내부 에러 가능성.
- 작성 완료 버튼을 눌러도 페이지 이동이 안 되는 문제 발생 → 원인은 위 오타와 콘텍스트/라우팅 흐름 확인 부족.


## Keep
- 상태 업데이트 함수 내에서 이벤트 객체를 재구성해 직접 핸들링하는 방식 (onChangeInput) 유지.
- 작성 완료 후 이동은 useNavigate()를 replace: true로 설정해 브라우저 기록을 깔끔하게 유지.
- context와 props를 적절히 연결하고, 단일 진입점(onSubmit)에서 데이터를 넘기는 구조 유지.


## Try
- input의 상태 키 이름과 input name 속성 이름은 항상 일치하도록 더블 체크할 것.
- key 값은 항상 고유하고 존재하는 필드로 명확히 지정.
- Button 컴포넌트처럼 커스텀 컴포넌트를 만들 때는 전달받은 onClick이 실제로 연결되는지 테스트할 것.
