# 2025-07-17
## Review
- sortType에 따라 동적으로 정렬 기준을 바꾸는 로직을 UI와 연결해 구현 완료.
- 감정 다이어리 데이터를 렌더링하는 과정에서, 데이터 구조를 더 깊이 이해할 수 있었음.


## Problem
- getEmotionImage() 함수에서 매개변수 이름 오류(imotionID → emotionId)로 이미지 렌더링 실패 경험.
- data.map() 중 undefined 접근 문제 발생 — 구조 점검 및 타입 변환을 통해 해결.


## Keep
- 문제 발생 시 콘솔 로그와 typeof 등을 적극적으로 활용해 디버깅한 점.
- 기능 단위로 로직을 함수화하여 코드 재사용성과 가독성을 높이려는 시도.


## Try
