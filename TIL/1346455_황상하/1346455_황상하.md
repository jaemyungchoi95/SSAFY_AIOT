### 🧠 개념 정리

- **쿠키**: 클라이언트(브라우저)에 저장되는 key-value 데이터.  
- **세션**: 서버에 저장되는 클라이언트 상태 정보.  
- **JSESSIONID**: 세션 식별용 쿠키. 요청마다 서버에 전달됨.  
- **만료 시점**: 쿠키는 설정 가능, 세션은 브라우저 종료 시 기본 만료.

### 🧠 개념 정리
- 입력 데이터	내부 폐곡선 영역 (clean_enclosed) – flood-fill로 외곽 제거 후, morphology로 노이즈 정제된 이미지
- 윤곽선 검출	cv2.findContours(clean_enclosed, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE) 사용
→ 외곽 경계만 추출 (중첩 안 봄)

- 박스 생성	cv2.minAreaRect(cnt)로 컨투어를 감싸는 기울어진 최소 사각형 구함
→ rect = (center(x,y), (w,h), angle)
- 박스 꼭짓점 변환	cv2.boxPoints(rect)로 네 꼭짓점 좌표 반환 후 정수형 변환
